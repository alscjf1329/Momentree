# 법률 검토 요청 요약 (이용약관·개인정보처리방침)

대상 파일: `src/app/terms/page.tsx`, `src/app/privacy/page.tsx` (화면: `/terms`, `/privacy`). 둘 다 법률 검토 전 초안이다. 코드 사실은 아래 근거 파일로 확인할 수 있다.

## 검토가 필요한 항목 (`[확정 필요]`로 남은 것)
1. **책임 제한 조항** — 약관 5항 마지막 줄 (`terms/page.tsx`의 `책임 제한 조항 (법률 검토)`). 현재 문안은 천재지변·장애 면책, 이용자 입력 정보의 정확성·이용자 간 분쟁은 이용자 책임, 계정 무단 사용 면책, 고의·중과실은 법령에 따라 책임. 책임 범위 세부(손해배상 한도 등)가 비어 있다.
2. **국외 이전 해당 여부와 고지 항목** — 방침 6항 마지막 줄. 아래 외부 서비스가 해당되는지, 해당하면 고지 문구.

## 사실관계 (코드·운영 기준)
- **운영 주체:** 사업자등록 없이 개인이 운영한다. 당근마켓 등에서 홍보하고, 유료는 계좌이체로 받는다(PG 없음). 방침·약관의 운영자 표기는 "개인이 운영하는 서비스", 문의처는 서비스 안 "문의하기"와 운영 메일(환경변수 `GMAIL_USER`)이다. 사업자 정보 표시·통신판매업·세금 문제는 법률·세무 확인이 필요하다.
- **서버:** 위탁 업체 없이 운영자 본인의 국내(집) 서버. 백업은 `bin/backup.sh`(최신 14개 보관), 외부 복사 여부는 운영자 확인 필요.
- **수집·저장 정보:**
  - 고객: 로그인 이메일(인증 코드는 해시로만 저장, 5분 유효), 청첩장 정보(이름·부모·예식 일시·장소·사진·인사말·계좌 등), 세션 쿠키 7일.
  - 하객: 참석 응답(이름·측·참석 여부·인원·동반인 이름·메시지)과 방명록(이름·메시지).
  - 고객 데이터 전체와 하객 응답·방명록·메일 큐는 AES-256-GCM으로 암호화해 저장한다(`src/lib/accountCrypto.ts`).
- **보관·파기:** 하객 응답·방명록은 예식일 6개월 후 하객에게 비공개, 12개월 후 자동 삭제(삭제 30일 전 고객 이메일로 안내). 청첩장·계정은 자동 삭제 대상이 아니며 삭제 요청 시 처리(요청일로부터 10일 이내, 문의하기로 요청). 청첩장 삭제 시 하객 응답·방명록·업로드한 사진·음악도 함께 삭제(`deleteCustomer`). 백업본에는 교체될 때까지 남을 수 있다.
- **외부 서비스(해외 사업자):**
  - Google LLC(Gmail SMTP): 인증 코드·공동 편집 초대·보관 안내 메일 발송 시 수신자 이메일과 메일 내용이 전달된다(`src/lib/mailer.ts`).
  - Google Fonts: 페이지 열 때 브라우저가 Google 서버에서 폰트를 받아 IP 등이 전달될 수 있다(`src/app/layout.tsx`).
  - 카카오맵 SDK(국내): 위치 지도 표시.
  - 텔레그램: 운영자에게 가는 문의·오류 알림(문의 내용이 전달됨).
- **요금·환불(초안):** 무료/유료(1회 19,900원, 구독 없음). 환불은 유료 전환 후 7일 이내이고 청첩장을 공유하기 전이면 전액, 공유 후에는 제한, 운영자 사정으로 이용 못 한 경우 전액. 이 7일 기준과 "공유 후 제한"이 청약철회 관련 규정에 맞는지 확인이 필요하다.
- **기한·고지(승인된 제안값):** 열람·삭제 요청 처리는 요청일로부터 10일 이내. 약관·방침 변경은 시행 7일 전 게시, 불리하거나 중요한 변경은 30일 전 게시와 가입 이메일. 서비스 중단·종료는 30일 전 안내(종료 시 내려받기 후 파기). 관할 법원은 "민사소송법에 따른 관할 법원".

## 함께 확인하면 좋은 질문
- 하객이 입력하는 정보에서 운영자와 고객(청첩장 주인)의 처리 관계(개인정보처리자/수탁자)를 방침에서 어떻게 표현할지.
- 개인정보 보호책임자를 "운영자 + 문의 이메일"로 표시하는 방식이 충분한지.
- 백업을 외부(클라우드 등)에 두는 경우 방침에 추가할 문구.
- 유료 판매 규모에 따른 사업자·통신판매업 신고 의무와 약관·방침 표시 사항.

수정 후에는 `[확정 필요]` 표시를 지우고, 문구가 바뀌면 `src/app/faq/page.tsx`의 삭제·보관·요금 답변도 같이 맞춘다.
