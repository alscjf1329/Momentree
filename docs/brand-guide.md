# Momentree 브랜드 가이드 (초안)

> 상태: 초안. 포인트 그린 색과 로고 방향은 확정 전이다 (MOM-17, MOM-18). 확정된 항목만 코드에 반영한다.

## 컨셉
**Moment + Tree** — 두 사람이 함께 자라는 순간을 담는다. 이름은 유지한다.

## 톤앤매너
- 따뜻하고 차분하다. 과장하거나 재촉하지 않는다.
- 서비스 내부 용어(데이터 파일, 슬러그, 어드민)를 사용자 화면에 노출하지 않는다.
- 존댓말, 짧은 문장. 예: "두 분의 하루를 링크 하나로."

| 쓰기 | 피하기 |
|---|---|
| 정보 입력 | 고객 정보 입력, 데이터 파일 |
| 링크 공유 | URL 생성 |
| 하객 응답 | RSVP 데이터 |

## 색상
`src/app/globals.css`의 토큰이 단일 출처다. 화면에서는 값을 직접 쓰지 않고 `var(--color-*)`를 쓴다.

| 토큰 | 값 | 용도 |
|---|---|---|
| `--color-cream` | `#faf6f1` | 배경 |
| `--color-primary-dark` | `#5c4035` | 제목, 주요 버튼, theme-color |
| `--color-primary` | `#8b6f5e` | 보조 강조 |
| `--color-gold` | `#c9a96e` | 포인트 |
| `--color-text` / `--color-text-light` | `#3d2e28` / `#7a6358` | 본문 |
| 포인트 그린 (제안, 미확정) | — | 나무 모티프. 승인 후 토큰 추가 |

## 타이포그래피
- 제목: Noto Serif KR (300/400/500), 자간 넓게
- 본문: Noto Sans KR
- 청첩장 템플릿 내부의 캘리그래피 폰트는 템플릿 개별 디자인이며 브랜드 폰트가 아니다.

## 로고
미정. 나무 모티프 워드마크 2~3안을 시안으로 만든 뒤 선택한다. 교체 대상: `public/icon.svg`, `icon-192.png`, `icon-512.png`.
