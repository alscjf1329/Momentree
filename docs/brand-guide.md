# 마당(Madang) 브랜드 가이드 (초안)

> 상태: 색은 확정(MOM-17), 로고는 B안 채택(MOM-18). 확정된 항목만 코드에 반영한다.

## 컨셉
**마당** — 사람들이 모이는 열린 자리. 청첩장뿐 아니라 부고·돌잔치·파티까지 어울리도록, 경사와 조사 어느 쪽에도 차분하게 쓴다.

## 이름 표기
- 한글 **마당**, 영문 **Madang**. 코드의 단일 출처는 `src/lib/brand.ts`(`SERVICE_NAME`, `SERVICE_NAME_EN`).
- 화면·메일 제목은 한글 "마당", 메일 발신자 표시와 영문 문맥은 "Madang". 소문자 `momentree`는 쓰지 않는다.
- 조사: "마당"은 받침(ㅇ)이 있어 "마당이", "마당으로", "마당은"이 맞다. 예: "마당으로 만든 청첩장".
- 내부 식별자(DB 파일 `momentree.db`, 컨테이너·경로, 저장소 키)는 데이터·배포 호환 때문에 옛 이름을 유지한다.

## 톤앤매너
- 따뜻하고 차분하다. 과장하거나 재촉하지 않는다.
- 서비스 내부 용어(데이터 파일, 슬러그, 어드민)를 사용자 화면에 노출하지 않는다.
- 존댓말, 짧은 문장. 예: "두 분의 하루를 링크 하나로."

| 쓰기 | 피하기 |
|---|---|
| 정보 입력 | 고객 정보 입력, 데이터 파일 |
| 링크 공유 | URL 생성 |
| 하객 응답 | RSVP 데이터 |

## 색상
인스타 감성 리디자인으로 **흑백 + 로즈 한 가지**로 확정했다. `src/app/globals.css`의 토큰이 단일 출처이고, 화면에서는 값을 직접 쓰지 않고 `var(--color-*)`를 쓴다.

| 토큰 | 값 | 용도 |
|---|---|---|
| `--color-ink` | `#111111` | 제목, 주요 버튼 |
| `--color-sub` | `#6B6B6B` | 보조 글자 |
| `--color-line` | `#EBEBEB` | 헤어라인, 테두리 |
| `--color-soft` | `#FAFAFA` | 옅은 배경 |
| `--color-rose` | `#C2255C` | 포인트 (초록 제안은 폐기) |
| 배경 | `#FFFFFF` | 앱 기본 배경 |

옛 크림·브라운·골드 토큰(`--color-primary`, `--color-gold` 등)은 청첩장 템플릿과 웨딩 테마에서만 쓴다. 앱 화면에는 쓰지 않는다.

## 타이포그래피
- 제목: Noto Serif KR (300/400/500), 자간 넓게
- 본문: Noto Sans KR
- 청첩장 템플릿 내부의 캘리그래피 폰트는 템플릿 개별 디자인이며 브랜드 폰트가 아니다.

## 로고
B 둘러앉은 원(흰 배경) 채택. 서비스명은 마당(Madang)으로 교체했다(MOM-43). 상표·도메인은 별도 진행. 시안: `docs/logo-proposals/`. 적용 파일: `public/icon.svg`, `icon-192.png`, `icon-512.png`, `icon-512-maskable.png`, `apple-touch-icon.png`.
